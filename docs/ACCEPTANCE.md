## 真实数据库验证

- Auth 用户创建触发器、真实密码登录、资料编辑、公共主页和关注。
- 同一天并发签到只发一份奖励；7/8 天循环、断签重置、连续 30 天奖励、每日/每周任务与可达的 100 分活跃度。
- 钱包、EXP 和流水由事务控制；同余额并发投掷只有余额允许的请求成功。重复投掷同一文章、多枚投掷、幂等重试、参数冲突和非负余额。
- 点赞与臭鸡蛋互不冲突；收藏迁移可重试且保留本地备份；阅读进度归属与最短阅读时间。
- 评论、回复、编辑、删除、评论点赞、动态及动态评论；关注 Feed、有效讨论奖励、基础垃圾内容规则。
- 聚合通知、已读隔离、举报去重、管理员权限、内容隐藏/恢复、账号限制/恢复，以及有审计与流水的资产调整。
- 表 RLS、客户端写权限、函数固定 search_path、私有函数权限、有效索引与必要触发器均查询实际数据库验证。

## 安全边界与运营事项

- 发布密钥可进入客户端；secret、数据库密码和 CLI token 不进入客户端或 Git。没有使用旧的 anon 环境变量。
- 所有经济操作以 `auth.uid()` 为准，受限账号由数据库拦截，客户端不能选择发奖对象或金额。管理角色与公开资料分表保存。
- 有效阅读要求至少 30 秒前台心跳和 30% 阅读深度；每账号只保留一个计时会话。客户端深度信号不能证明人真的阅读，这是轻量防刷而非身份或注意力验证。
- 访客浏览按网关提供的 IP（不可用时使用共享匿名桶）与站点日期盐化去重；登录用户按账号去重。阅读量表示去重后的阅读，不表示每次刷新。
- 每日签到按站点日历，周任务按周一计算；奖励自动入账，不另设可重复点击的领取入口。周活跃度按不同内容计数并封顶。
- 每日任务 EXP 合计最多 25，签到与每周任务单独计算。阅读勋章累计有效篇次，同一作品每日最多一次，使 54 篇文集中的百次阅读勋章也可通过长期重读获得。
- 臭鸡蛋只能投文章，不针对普通用户或评论，不自动改变作者权限、文章状态或搜索排序。不能购买、转账、提现或兑换现实商品。
- 邮箱送达、生产域名、SMTP、备份保留及主机 HTTPS 需要按实际运营环境配置。本次不代替未知的生产部署，也不授予不明账号管理员权限。
- 本地 Auth 回调地址已通过 CLI 配置为 4321 端口，邮箱确认保持开启，最低密码长度为 8。注册接口对保留测试域名返回 `email_address_invalid`；本次没有真实收件邮箱，未验证确认邮件送达与点击确认，不能把测试账号登录通过视为邮件链路验收。
- 暂不开放补签；后续需要补签券时，应新增迁移和自然月额度测试。

## 执行

常规验收：`npm run check`、`npm run test:db`。依赖审计：`npm audit --omit=dev --audit-level=moderate`。若远程连接超时，应恢复连接后重新运行失败项，不删除断言、不关闭 RLS，也不改用假数据。
