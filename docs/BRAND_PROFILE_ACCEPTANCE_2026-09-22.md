# 一班集 · 品牌图标与个人主页调整

本轮按“站点图标、统一书名、主页社交信息、资料设置迁移、本人/他人视角”实施。代码保留在本地，未合并、未推送或发布前端。

## 品牌

- 原创 SVG：朱砂色圆角底、“一”字横画、展开的书页。标签栏、页头和手机收藏图标使用同一母版。
- 包含 SVG、16/32/48px ICO、180px Apple 图标、192/512px PNG 及 webmanifest。重建命令为 `node tools/generate-brand-icons.mjs`。
- 首页、页脚、书籍元信息、PDF Subject/扉页统一为“一班集”；原“第二版序”展示标题改为“开卷序”，原链接 `/articles/preface2/` 保持可用。
- 迁移同步了数据库文章标题，目录、搜索、引用作品、下载文件名共用一致的标题。
- 全文核对仅保留小说《天花板·空栏》中关于方案修订的“第二版”叙述，它不是站点或书籍版本名。
- 修改标题前逐篇验证 SHA-256：54 篇的正文、章节、注释、署名和日期均未变化；只更新经本次要求批准的序言标题校验值。

## 个人主页

- 公开主体是头像字标、姓名、简介、加入日期、关注/粉丝数量，以及帖子/评论。
- 关注和粉丝可展开查看书友列表；按 20 人分页，支持空状态、失败重试、旧请求忽略和焦点返回。
- 关注/取消关注后数量同步更新。
- 个人资料从阅读设置移入自己主页的编辑弹窗；支持名称、简介、用户名，用户名变化后跳转到新主页。
- `/me/` 为稳定的本人入口，登录默认进入主页。阅读设置只保留阅读偏好及主页链接。
- “我的墨迹与成长”仅自己可见，放在公开活动之后，默认收起；等级样式预览和成就记录保留。
- 自己可切换“预览他人视角”，隐藏资料编辑、成长详情和管理操作；预览状态可刷新保留，并可一键返回本人视角。预览中的关注/互动不可执行。

## 隐私与实现

已演练并应用增量迁移 `20260922000300_profile_privacy_and_brand.sql`：

- 公开等级徽标继续读取粗粒度 level；具体 exp、更新时间不再允许直接公开读取。
- 成就解锁历程受本人 RLS 保护。
- 公开主页接口仅在请求者为本人时返回具体成长和成就历程；访客及其他账号收到空详情。
- 资料编辑仍由服务端 save_profile 的账号、所有权和校验规则约束。前端不把个人设置作为所有登录用户都可见的通用区域。
- 新脚本按主页状态、资料编辑、关系列表分开；不复制原先阅读设置中的事件绑定。
