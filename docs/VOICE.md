# 一班集文案准则

口吻像一本认真编过的文集，也像老同学之间说话：亲近、具体，有余味，不替读者抒情。

## 把诗意放在有来历的地方

- 首页保留“那时的风，还在纸上。”，由课桌、晚自习和班级文集的来历支撑。
- 投稿入口“后来写的，也放在这里。”，连接旧文集与今天的新作。
- 收藏页“读到喜欢的地方，折个角。”，借读书动作表达收藏。
- 社区“书可以合上，话还可以接着聊。”，从阅读自然转入交流。
- 页脚“书有末页，故事没有。”，回应仍在续写的文集。

一屏留一处主要的文学表达。小标题、眉题和说明不要围绕同一个比喻重复三遍；必要时直接删去装饰句。不堆叠“回响、相遇、温柔、每一个、篇章”等泛化表达，也不追求处处金句。

## 功能信息要具体

导航和动作使用投稿、作品、我的创作、我的书房、保存、发布、收藏等稳定称呼。书签、折角可以用于说明，操作仍叫“收藏”。等级积累统一称“墨迹”，不给认证作者额外添加名家等头衔。

加载说明正在加载什么；错误说明发生了什么、已保留什么、下一步能做什么。保存提示必须区分本机、云端与尚未保存。搜索为空、关注为空和全站没有作品分别说明，不把无结果写成抒情邀请。

奖励文案保留条件、上限、有效阅读和隐私说明，不写“每次都有奖励”“总有人会读到”等无法保证的承诺。作品是否公开、发布和撤回的后果要直说。

## 修改边界与检查

只修改网站界面和系统提示，不改原文、用户作品、真实简介或已经产生的用户内容。等级名称和机制不随文案润色改变。数据库存量通知及规则名称如需调整，单独核对迁移范围。

同时检查初始 HTML 与脚本加载后的文字，避免标题被旧文案覆盖。桌面和手机都核对标题换行、按钮宽度和留白。文案选择器随既有测试更新，原文完整性保持不变。
