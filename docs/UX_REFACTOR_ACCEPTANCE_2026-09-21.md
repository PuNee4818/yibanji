## 最终代码与样式审计

- CSS 按颜色变量、基础、布局、共享组件、页面、动效和无障碍层拆分，通过 `@layer` 明确层级。
- 移除旧的重复收藏事件和零散覆盖；所有操作继续复用现有服务端事务，不创建桌面/手机两套状态。
- `tools/audit-styles.mjs` 解析 430 条规则：无重复规则块、重复属性、同条件的跨文件重复覆盖；`!important` 仅用于隐藏、减少动态效果和打印。
- 社区与评论分页只在成功后前进；失败保留已有内容；重试不漏页、不重复；异步排序/标签切换忽略过期结果。
- 搜索取消过期请求，支持超时与分来源降级；用文本节点安全生成高亮和预览；搜索重绘保留重试入口。
- 首页索引网络失败保留静态精选；热文不可用时明确说明；云端续读不覆盖正在操作的读者，且不在本地恢复后再次跳动。
- PDF 页脚不再触发额外空白页；通过字体嵌入和文本提取检查完整性。
- 修正加载提示的 ARIA 语义和浅色辅助文字对比度；更新真实用户操作测试以使用新的更多菜单。
- 测试失败时也执行专用账号清理；本轮早先失败留下的 4 个测试账号已按 trace 中的准确标识清理。

## 维护与复现

- `npm run check`：构建、类型、lint、样式、单元、内容、完整浏览器回归。
- `npm run test:db`：真实数据库集成测试，使用专用测试账号。
- `npm run test:deploy`：本地生成并检查 Vercel 产物。
- `npm run pdf`：生成 PDF；首次需要数分钟，按内容/生成器/字体指纹缓存。
- `python tools/verify-pdfs.py --render`：需要 PyMuPDF，核验全文并输出抽样 PNG。
- `python tools/subset-reading-font.py`：需要 fontTools 和 Brotli；新增正文后更新网页字体子集。
- 完整字体约 24.5 MB，仅构建 PDF 使用；网页 WOFF2 约 1.53 MB。字体原始来源和 OFL 许可随仓库保留，PDF 不依赖用户电脑安装字体。

本地证据位于被 Git 忽略的 `tmp/ux-review/`：完整浏览器日志、数据库日志、发布产物日志、响应式检查、动态内容无障碍结果、首页/社区/阅读/搜索截图，以及 PDF 渲染与完整性报告。
