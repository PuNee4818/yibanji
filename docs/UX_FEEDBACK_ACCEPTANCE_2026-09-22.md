# 一班集 · 社区与阅读体验复审

本轮接续 [整体重构验收](UX_REFACTOR_ACCEPTANCE_2026-09-21.md)，处理浏览器批注及新增的等级、发帖要求。代码保留在本地工作区；没有合并、推送或发布前端。已连接的 Supabase 数据库应用了下文两项增量迁移。

## 交付

| 反馈 | 实现 |
| --- | --- |
| 悬浮效果生硬 | 移除热文、卷目上的矩形渐变覆盖和整卡抬升。标题与阅读入口轻微位移，阅读图标独立响应；社区引用卡片改为稳定纸面与细线。 |
| 首页动画跳回 | 叶片首尾回到同一自然角度，动画保留终态。自动检查动画结束与静态几何位置一致。 |
| 跳转迟滞 | 对公开静态页面按悬停、键盘焦点和触摸预取 HTML；头部与正文分开进行原生跨页转场，优先载入正文字体。预取不执行阅读或互动脚本；弱网络与省流量偏好保留浏览器降级。 |
| 阅读侧栏 | 去掉“更多”，直接放置点赞、评论、收藏、PDF、分享、沉浸阅读和臭鸡蛋；统计拆成四行。手机底栏在 320px 仍容纳七个操作。 |
| PDF | 单一预览入口，页内真实渲染、上一页/下一页、缩放、本章/全书切换；下载同一 PDF，文件名使用作品名，分章带章节名。失败可重试，也可下载或另页打开。 |
| 默认控件 | 统一选项框、可定制原生选项弹层、滚动条、占位文字、选择控件和键盘焦点；浏览器不支持新选项弹层时保留原生行为与统一的控件外观。 |
| 社区图标 | 星芒换为与站内线性图标同风格的纸页符号。 |
| 等级 | 评论、帖子、个人主页、成长页和账号菜单复用六组同形徽标，以色相、罗马序号和名称区分。主页及成长页可预览六级，预览不修改实际等级；签到刷新菜单等级。 |
| 帖子与评论分开 | 社区分“帖子广场 / 文章评论”，分别查询及分页；个人主页也分帖子和评论。帖子拥有独立详情及回复区，文章评论链接原作品。 |
| 主流发帖流程 | 独立编辑页，80 字标题、四类话题、10000 字正文、可搜索引用作品、按账号保存的本机草稿、预览、发布与编辑。兼容旧草稿、旧帖子、旧发帖接口；搜索支持帖子标题与正文。 |

原有 54 篇作品及 20 章正文未改写。已有 74 份 PDF 继续使用经过排版校验的静态文件，预览与下载共用文件。

## 数据与代码审计

- `20260922000100_posts_and_public_levels.sql`：新增帖子标题、话题及长正文支持；扩展公开讨论视图的等级和搜索字段；新增独立发帖事务及社区分流查询。旧帖子补上摘要标题，原正文、ID、评论保留。
- `20260922000200_post_read_visibility.sql`：仅收紧帖子公开读取条件。关联文章停用或帖子删除后，直接读表、搜索与回复均不能泄露内容。
- 两次迁移均先在回滚事务内演练，再应用。审计中曾考虑清空删除帖子的标题，自动审批拒绝该不可逆写入；最终采用保留数据、收紧读取权限的方案。没有执行清空标题的操作。
- 新增事务沿用账号限制、所有权、字数、频率、重复内容及请求幂等保护；隐藏文章引用按相同权限处理。前端标题、正文、预览继续使用安全文本节点。
- 清除旧更多菜单样式、渐变覆盖伪元素、未使用规则和重复按钮配色。最终样式审计覆盖 522 条规则，无重复块、重复声明或冗余同作用域/跨文件覆盖。
- 修复实际检查发现的热文序号对比度、极窄屏底栏溢出、PDF 异步取消与重新打开、删除帖子后的页面恢复、菜单等级刷新。
