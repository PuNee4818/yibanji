# 自由来稿

独立投稿板块与原文集、社区并列。主导航「投稿」、首页「写一篇文章」及「这本书，也可以有你的一页」均可进入。作品发布后立即公开，没有投稿审核队列。

## 使用

- `/submissions/`：按标题、作者、正文与标签搜索，按文体、主题、千字短文筛选；支持最新、近期受欢迎、关注作者及随机阅读。
- `/write/`：先写后登录，支持多篇草稿、本机恢复、登录后云端自动保存、专注模式、预览和文字备份。一个文体，最多五个主题标签；内置 16 种文体、22 个主题，也可输入自定义主题。
- `/me/writing/`：查看草稿、已发布、已撤回作品。已公开作品的修改稿列入草稿，读者继续阅读上一次公开版本，直到作者点击更新发布。
- `/submissions/[id]/`：服务端输出正文，支持阅读设置、目录、点赞、收藏、分享、关注作者、评论与同类阅读。
- 个人主页「作品」、全站搜索「投稿作品」、收藏与阅读历史中的「自由来稿」均已接入。

文体：散文、随笔、现代诗、古体诗、词、短篇小说、微型小说、小说、书信、日记、游记、回忆录、书评、杂文、剧本、其他。

编辑器使用纯文字与少量排版标记。工具栏可插入小标题（`##`）、加粗（`**文字**`）、引用（`>`）、分隔线（`---`），无需手动调整字体和段距。散文空行分段；诗歌保留换行、连续空行及行首空格。预览与阅读页共享解析规则，用户 HTML 作为文字显示。

目前小说支持单篇长文和文内分节，正文上限十万字；多章连载管理与图片上传不在本次范围。

## 保存与权限

- `submission_drafts` 保存私人稿件；`submissions` 保存显式发布的快照。草稿表只允许本人读取，所有写入走数据库 RPC。
- 保存携带版本号和幂等标识。过时版本不能覆盖新稿；冲突时另存本机恢复副本，并允许把当前文字保存为新草稿。
- 本机草稿按账号隔离。登录前的稿件仅在返回同一草稿时迁入当前账号。账号变化时锁定编辑，保留原账号本机稿件。
- 发布、更新、撤回和删除均校验作者身份。撤回立即退出公开阅读、搜索、主页与收藏列表；评论随作品公开状态决定可见性。
- 点赞、收藏和阅读进度分别存储；收藏与进度仅本人可读。投稿与原文集文章、社区帖子使用独立标识和数据表。
- 投稿阅读页设置 `Cache-Control: no-store`，不需要重新构建网站便能读取发布或撤回后的状态。

## 数据库和验证

新增增量迁移：`20260922000400_submissions.sql`、`20260922000410_submission_genre_filter.sql`。第一份迁移先在事务中演练回滚，再由现有迁移工具应用；第二份明确区分现代诗、古体诗和词的筛选。

针对性测试：

```sh
node --test tests/unit/submissions.test.mjs
node --test tests/integration/submissions.test.mjs
npx playwright test tests/e2e/submissions.spec.ts tests/e2e/writing-recovery.spec.ts
```

数据库测试验证匿名／其他账号的草稿访问、版本冲突、幂等发布、私人修改不公开、搜索、收藏隐私、评论、撤回和删除。浏览器测试覆盖桌面和手机、诗歌预览、登录续写、断网恢复、冲突保留、主页与搜索联动、夜间样式和 WCAG AA 自动扫描。真实测试账号与作品在测试后清理。

全站回归使用 `npm run check`，部署产物检查使用 `npm run test:deploy`。视觉截图与日志保存在忽略提交的 `tmp/ux-review/` 和 `tmp/submissions-*.log` 中。
