# 自由来稿

独立投稿板块与原文集、社区并列。主导航「投稿」、首页「写一篇文章」及「这本书，也可以有你的一页」均可进入。作品发布后立即公开，没有投稿审核队列。

## 使用

- `/submissions/`：展示热门作品、近月主题与创作奖励入口；按标题、作者、正文与标签搜索，按文体、主题、千字短文筛选，支持最新、热门、关注作者及随机阅读。
- `/write/`：先写后登录，支持多篇草稿、本机恢复、登录后云端自动保存、专注模式、预览和文字备份。一个文体，最多五个主题标签；内置 16 种文体、22 个主题，也可输入自定义主题。
- `/me/writing/`：查看草稿、已发布、已撤回作品。已公开作品的修改稿列入草稿，读者继续阅读上一次公开版本，直到作者点击更新发布。
- `/submissions/[id]/`：服务端输出正文，与目录文章共用 `ReaderFrame`、互动栏、阅读设置、目录、沉浸模式、点赞、收藏、臭鸡蛋、评论回复与阅读进度。动态投稿通过浏览器打印导出 PDF，目录文章保留预生成 PDF 预览。
- 个人主页「作品」、全站搜索「投稿作品」、收藏与阅读历史中的「自由来稿」均已接入。

文体：散文、随笔、现代诗、古体诗、词、短篇小说、微型小说、小说、书信、日记、游记、回忆录、书评、杂文、剧本、其他。

编辑器使用纯文字与少量排版标记。工具栏可插入小标题（`##`）、加粗（`**文字**`）、引用（`>`）、分隔线（`---`），无需手动调整字体和段距。非诗歌换行自动分段，去除手工行首空格，统一由样式控制缩进；诗歌保留换行、连续空行及行首空格。预览与阅读页共享 `formattedWriting` 与 `writingStyle`，用户 HTML 作为文字显示。

- 散文、随笔、游记等：舒适段距、可选两字缩进、开篇首字下沉。
- 小说：较紧凑段距；独立一行的“第一章 … / 第二节：…”自动形成章节标题和目录，章节开篇支持首字下沉。
- 现代诗：左对齐、保留诗行与空行；古体诗居中；词保留上下阕，采用居中的版心与左对齐诗行。诗歌不使用首字下沉或自动缩进。
- 书信、日记、剧本：保留各段分行，不使用首字下沉；剧本不自动缩进。
- 阅读者可以在共用阅读设置中关闭首字下沉，字号、行距、版心与纸色沿用全站偏好。

目前小说支持单篇长文和文内分节，正文上限十万字；多章连载管理与图片上传不在本次范围。

## 保存与权限

- `submission_drafts` 保存私人稿件；`submissions` 保存显式发布的快照。草稿表只允许本人读取，所有写入走数据库 RPC。
- 保存携带版本号和幂等标识。过时版本不能覆盖新稿；冲突时另存本机恢复副本，并允许把当前文字保存为新草稿。
- 本机草稿按账号隔离。登录前的稿件仅在返回同一草稿时迁入当前账号。账号变化时锁定编辑，保留原账号本机稿件。
- 发布、更新、撤回和删除均校验作者身份。撤回立即退出公开阅读、搜索、主页与收藏列表；评论随作品公开状态决定可见性。
- 投稿发布快照同步为 `articles` 中 `source='submission'` 的条目，UUID 文本作为共用文章标识。点赞、收藏、评论、进度和阅读任务使用现有 `article_likes`、`bookmarks`、`comments`、`reading_progress` 与统一 RPC；社区帖子继续独立。
- 旧投稿互动已搬迁到共用表；旧接口转为兼容视图或代理函数，不再双写。旧表暂存在私有 schema 供核对，浏览器无读取或写入权限。
- 撤回与删除会停用对应文章标识，公开文章、讨论、搜索、推荐和收藏列表统一隐藏。收藏者身份与阅读进度仅本人可读；公开总数不透露收藏者。
- 投稿阅读页设置 `Cache-Control: no-store`，不需要重新构建网站便能读取发布或撤回后的状态。

## 统一阅读、创作奖励与作者认证（后续改版）

迁移 `20260922000500_unified_reading.sql`、`20260922000510_author_verification.sql`、`20260922000520_writing_fingerprints.sql` 已应用。前两项先合并进行事务演练并回滚，持久化应用在用户明确授权后进行。

奖励使用已有墨迹账本，只有服务端可发放：

| 行为 | 墨迹 | 限制 |
| --- | --- | --- |
| 合格作品发表 | +60 | 同一作品一次，每天前两篇 |
| 首次获得发表奖励 | +40 | 账号一次，不追溯旧作品 |
| 作品获得有效点赞 | +8 | 每位读者、每篇作品一次 |
| 作品获得有效收藏 | +12 | 每位读者、每篇作品一次 |

诗歌门槛为 20 个文字或字母，其余 120 个，不计标点与排版符号。未达到门槛仍可发布。认可奖励要求读者注册满 24 小时，并完成共用系统的有效阅读；先操作、后完成阅读也会结算。自己给自己互动不计奖，同一读者每天为同一作者最多贡献 40，作者每天认可奖励上限 200。上限之外的互动不次日补领。奖励记录、所有公开版本的正文指纹会保留，防止反复取消、修改、撤回或删稿重发刷奖励。奖励流水使用随机幂等标识，不泄露收藏者账号。

认证为管理端确认的身份标识，不是付费等级或投稿审核。公开显示统一“认证作者”标签，与等级并列；普通用户不可通过编辑资料自行修改认证。管理页面支持按用户名授予、撤销认证，并记录依据和审计日志。文集署名使用受保护的 `catalog_authors` 映射，不依赖昵称同名匹配。张贺然与王俊舾两个现有账号已认证并关联原文集署名；未关联账号的作者使用 `/authors/[name]/` 公共作品页。关联后该入口重定向个人主页，主页同时展示文集收录和新投稿。

热门排序使用近七日点赞、收藏、不同读者的评论、对数阅读数与时间衰减，不使用臭鸡蛋作为正向推荐信号。推荐与关注动态仅在站内展示，不发送站外推送。游客投稿收藏和阅读记录已加入本机书房，首页支持继续阅读投稿。
